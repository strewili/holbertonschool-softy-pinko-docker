# Task 5 — Proxy Server

نضع **Nginx كـ proxy** أمام كل شيء على المنفذ 80. العميل يعرف عنواناً واحداً
فقط، والـ proxy يوجّه داخلياً.

## التوجيه

| المسار | يذهب إلى |
| --- | --- |
| `/` | `http://front-end:9000` |
| `/api` | `http://back-end:5252` |

## نقاط مهمة

- **أسماء الخدمات تعمل كأسماء نطاقات**: Docker فيه DNS داخلي يحوّل
  `front-end` و `back-end` إلى عناوين IP الحاويات تلقائياً — لا حاجة لمعرفة
  أي IP.
- **نحذف ربط المنافذ** عن الواجهة والـ API. المنفذان 9000 و 5252 يبقيان
  مفتوحين **داخلياً** بين الحاويات، لكن لا يصلهما أحد من الخارج. كل شيء
  يمر عبر المنفذ 80.
- **الـ AJAX يتغيّر** من `http://localhost:5252/api/hello` إلى `/api/hello`
  — مسار نسبي يمر عبر الـ proxy نفسه، فينتهي مشكل CORS من أصله.

```bash
docker-compose build
docker-compose up
curl http://localhost/api/hello
```
