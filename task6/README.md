# Task 6 — Scale Horizontally

نشغّل **نسختين** من خدمة الـ API، و Nginx يوزّع الطلبات بينهما بخوارزمية
**Round-Robin**.

## التوسّع الأفقي مقابل الرأسي

| | أفقي (Horizontal) | رأسي (Vertical) |
| --- | --- | --- |
| الطريقة | نضيف أجهزة/حاويات أكثر | نكبّر الجهاز الواحد |
| السقف | لا سقف عملي | محدود بأقوى جهاز متاح |
| التوقّف | بدون توقّف | يحتاج إعادة تشغيل |
| تحمّل الأعطال | يستمر لو سقطت نسخة | نقطة فشل واحدة |

## كيف يشتغل

`docker-compose up --scale back-end=2` ينشئ حاويتين باسمي `task6-back-end-1`
و `task6-back-end-2`. الـ DNS الداخلي لـ Docker يُرجع عنواني الحاويتين لنفس
الاسم `back-end`، و Nginx يوزّع الطلبات عليهما بالتناوب — بدون أي تعديل على
`proxy.conf`.

```bash
docker-compose up --scale back-end=2
```

الأمر محفوظ في `2-api-servers.txt`.
